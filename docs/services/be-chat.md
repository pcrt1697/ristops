# be-chat

Chat service for the AI assistant. Owns conversations — chats, messages and pending actions — and
runs each turn by building an agent from [lib-agent](../libraries/lib-agent.md) and streaming its
events back to the BFF.

> Source: [ristops-be-chat](https://github.com/pcrt1697/ristops/blob/main/ristops-backend/packages/ristops-be-chat/README.md)

**Status:** bootstrapped, not implemented yet. The design is a draft in
[AI assistant design](../design/ai-assistant.md); this page will describe the service once it is
built.
